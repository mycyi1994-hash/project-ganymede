# 결선 채점자 5인 페르소나 평가 (내부용)

비공개 개발 저장소 전용 문서다. 공개 스냅샷에는 넣지 않는다(`docs/SUBMISSION_EXPORT.md`의 제외 목록).
2026-10-03 운영(`ganymede-xlayer`)과 저장소를 각 페르소나가 직접 써 보고 매긴 점수다. 10점 만점.

## 페르소나

| # | 채점자 | 보는 것 |
| --- | --- | --- |
| 1 | **X Layer 생태계 리드** (OKX) | OKX 스택(OnchainOS·OKX Wallet·탐색기·OKX.AI)을 얼마나 깊게 쓰는가, X Layer에 무엇을 더하는가(다른 앱이 가져다 쓸 수 있는가) |
| 2 | **DeFi 보안 엔지니어** | 컨트랙트 설계, 관리자 권한, 오라클 신뢰, 시험·퍼즈·정적 분석, 장애 시 동작 |
| 3 | **프로덕트·UX 리드** | 처음 온 사람이 1분 안에 쓸 수 있는가, 휴대폰, 오류·빈 상태, 속도, 접근성 |
| 4 | **VC·사업 파트너** (OKX Ventures) | 시장, 수익 모델, 실사용·성장 증거, 규제 경로, 실행력 |
| 5 | **AI·개발자 경험 심사위원** (OKX.AI·Onchain OS) | 에이전트 연동(MCP), API 문서·명세, 재현성, 예제 |

## 기준선 (개선 전)

### 1. X Layer 생태계 리드 — 8.5
- 강점: OnchainOS Market API로 5분마다 xStocks 가격, X Layer 메인넷 xStocks·Uniswap V3 풀 직접 읽기, X Layer Testnet 컨트랙트 11개(출처 검증), OKX Wallet 우선 연결과 `wallet_watchAsset`, 모든 기록의 OKX 탐색기 링크, Chainlink 호환 피드, MCP 서버(OKX.AI A2MCP 등록).
- 감점: OnchainOS는 가격 API 하나만 쓴다. "여섯 종목을 따로 사면 스왑 여섯 번"이라는 주장이 실제 OKX DEX 견적 없이 말로만 있다. OKX 앱 브라우저로 바로 여는 길이 없어 휴대폰 OKX Wallet 사용자가 막힌다. OKX.AI 등록은 승인 전이라 증거가 없다.

### 2. DeFi 보안 엔지니어 — 8.0
- 강점: 컨트랙트 시험 99개, 훅 불변식 퍼즈 1,000단계, Slither 135건 분류, 출처 검증, NAV 1시간 만료와 주문 최소 수령량, 부하 시험 618건 실패 0.
- 감점: 관리자 키가 무엇을 할 수 있는지(그리고 못 하는지) 한곳에 정리된 것이 없다. 사용자가 확인할 방법도 없다(체인에서 읽어 보여 주는 화면이 없다). 위협 모델·취약점 신고 절차 문서가 없다. 대출 시장의 퍼즈 시험이 없다.

### 3. 프로덕트·UX 리드 — 8.3
- 강점: 실제 서비스 같은 화면, 세 곳 견적 자동 라우팅, 0.17초 API, 실시간 Ask USTX, 접근성 검사 위반 0, 휴대폰 가로 넘침 0, 전 컨트롤 클릭 오류 0.
- 감점: 지갑 투자를 시작하려면 외부 faucet에서 테스트 OKB를 먼저 받아야 해서 첫 사용자가 대부분 여기서 떠난다. 휴대폰 OKX 앱에서 여는 안내가 없다. Ask USTX가 "New chat" 뒤 Esc로 닫히지 않았다(수정).

### 4. VC·사업 파트너 — 7.5
- 강점: 단가 측정($0.00016/기록, 월 $1.40), 발행사 페이지, 설정 파일로 새 바스켓(MAG3), 실제 돈은 규제 파트너 이후라는 정직한 선 긋기.
- 감점: 수익 모델이 "문의"뿐이다. 실사용 증거가 없고, 있는 활동도 팀 지갑과 섞여 있어 구분이 안 된다. 메인넷까지의 단계(누가 발행·보관·인가)가 한눈에 없다.

### 5. AI·개발자 경험 심사위원 — 8.5
- 강점: 읽기 전용 MCP 도구 6개, AI 클라이언트 연결 예시, 실시간 스트리밍 Ask USTX(도구 근거 표시), 공개 API 3종, 증거 파일 재검증 명령.
- 감점: API의 기계가 읽는 명세(OpenAPI)가 없다. 에이전트용 안내(`llms.txt`)가 없다. 바로 돌려 볼 에이전트 예제가 없다. OKX.AI 등록 증거가 없다.

### 1. X Layer 생태계 리드 — 8.5 → 9.1
- 근거: OnchainOS를 두 API로 쓴다. 가격 API에 더해 DEX 집계기 견적 API가 한 시간마다 X Layer 메인넷에서 xStocks 6종의 견적을 받는다(`/api/v1/ustx/dex-quotes`). 첫 견적(06:19 UTC) 기준으로 $1,000을 여섯 번 스왑하면 서명 6번(처음엔 승인 6번 더), 집계기 가격 기준 손실 $1.40(0.14%), 네트워크 수수료 약 $0.009, 최대 가격 영향은 AMZNx 0.51%였다. 경로는 Uniswap V3와 xStocks wrap이다. "여섯 번 따로 산다"는 주장이 이제 실제 OKX 숫자로 뒷받침된다. 휴대폰에서 지갑이 없으면 OKX 범용 링크로 "Open in the OKX app"이 뜬다(운영에서 링크가 현재 페이지를 담는 것을 확인).
- 남은 감점: OKX.AI 등록 증거가 없다. DEX 견적을 보면 직접 사는 비용이 작아서, USTX의 가치는 비용보다 한 번의 주문, 검증 가능한 NAV, 리밸런싱에 있다고 말해야 한다.

### 2. DeFi 보안 엔지니어 — 8.0 → 8.7
- 근거: Transparency의 "Who controls the contracts"가 9개 컨트랙트의 관리자·발행자·민터·소유자·일시정지를 방문자 브라우저에서 읽고, 각 역할이 할 수 있는 일과 없는 일을 보여 준다(운영: 9행, 일시정지 없음). `SECURITY.md`에는 권한 목록, 신뢰 가정(발행자 키 탈취 시 영향 포함), 시험 내역, 신고 절차가 있다. 대출 시장 불변식 퍼즈 시험은 2,000단계를 돌았고 대출 74건, 청산 8건, 상환 98건 동안 장부 일치·지급 능력·한도·청산 조건·일시정지 중 출구 유지·전원 퇴장을 확인했다. 컨트랙트 시험은 100개다.
- 남은 감점: 외부 감사가 없다. 관리자는 단일 EOA이고 멀티시그나 타임락이 없다.

### 3. 프로덕트·UX 리드 — 8.3 → 9.0
- 근거: 테스트 OKB가 거의 없는 지갑은 USTX·Pools·Borrow 화면에서 "Get free test OKB"를 한 번 눌러 0.0005 OKB(거래 약 100번 분량)를 받는다. 운영에서 새 지갑으로 연결 → 버튼 → OKB 도착 → dUSD 받기까지 외부 faucet 없이 성공했다. 재요청, 다른 출처, 잔액이 있는 지갑은 거절된다. 휴대폰에는 OKX 앱 열기가 있고, Ask USTX의 Esc 버그를 고쳤다. 새 화면들은 데스크톱·휴대폰 모두 접근성 위반 0, 가로 넘침 0이다.
- 남은 감점: 가스 받기와 dUSD 받기가 아직 두 번의 클릭이다. 첫 방문 안내(체크리스트)가 없다.

### 4. VC·사업 파트너 — 7.5 → 8.1
- 근거: 발행사 페이지에 수익 모델이 생겼다. 발행사 수수료 공유, 유통 몫, 검증된 NAV 피드 구독이고, 예시로 $10M 바스켓에 연 0.15%면 연 $15,000이며 가스비는 약 $17다. 메인넷까지의 4단계(감사 → 메인넷 NAV를 가격 피드로만 → 인가 발행사와 수탁 → 유통)도 적었다. `/api/v1/ustx/usage`는 팀·시험 지갑 35개를 분리해 사용량을 공개한다: 팀 밖 지갑 2개(70건, 9/25), 팀·시험 452건, Ask 질문 수.
- 남은 감점: 실사용 견인력이 사실상 없고, 이제 그게 숫자로 공개돼 있다. 정직함은 신뢰를 높이지만 견인력 점수를 올리지는 못한다. 파일럿 고객과 인가 파트너가 없다.

### 5. AI·개발자 경험 심사위원 — 8.5 → 9.1
- 근거: OpenAPI 3.1(`/api/v1/openapi.json`, 경로 6개), 에이전트 안내 `/llms.txt`, 의존성 없는 MCP 클라이언트 예제(`examples/agent-quote.mjs`, 운영에서 실행해 펀드·v4·상수곱 견적을 받았다)가 생겼고, 개발자 페이지와 README에서 연결된다. 사용량·DEX 견적도 공개 API로 열었다.
- 남은 감점: OKX.AI 등록 증거가 없다. MCP 도구는 6개 그대로이고, 사용량·DEX 견적 도구가 아직 없다. SDK 패키지가 없다.

### 다음에 점수를 더 올릴 일
1. 관리자를 멀티시그(또는 타임락)로 옮긴다. 컨트랙트 관리자 조치라 사용자 승인이 필요하다.
2. MCP에 `get_ustx_usage`, `get_dex_quotes` 도구를 추가한다.
3. 첫 방문 체크리스트로 가스 → dUSD → 투자를 한 흐름으로 묶는다.
4. 외부 사용자를 실제로 모은다(커뮤니티 테스트 행사). 팀 지갑 분리 지표가 바로 증거가 된다.
