# Ganymede 제품 화면 통합 배포

2026-09-24 · `codex/product-redesign-1-3`

## 확정된 범위

사용자가 전달한 저장소·배포 확인에 따라, 이번 제품의 실행 범위는 **USTX 모델 NAV와 구성 공개, 기존 CORE 테스트넷 지분 장부 읽기, 별도 Lab 모의 운용**이다. 실제 입출금·자산 취득·보관·지급·결제 토큰을 새로 만들거나 지정하지 않는다. 실제 투자·회수 구현은 완료한 것으로 표시하지 않는다.

USTX와 GMDCORE는 다른 대상이다. USTX는 지분·결제 계약이 없는 모델 바스켓이다. 배포된 `GanymedeFundShare`는 X Layer Testnet(1952)의 CORE 장부이며, 발행자 mint/burn은 입금·출금 증거가 아니다.

## 전체 화면

| 경로 | 완료한 동선 |
| --- | --- |
| `/` | Markets → USTX 구성·공개 NAV 이력 → 상세 |
| `/products/ustx` | 이력, 구성 선택, 상품 조건, 미개방 상태, Transparency |
| `/products/ustx/transparency` | 직접 RPC·문서 해시·계산의 자동 대조. 기술 근거는 접는 영역 |
| `/portfolio` | 지갑 공개 계정 또는 입력 주소 → 실제 GMDCORE 잔액 → 최근 기록 |
| `/activity` | 같은 공개 주소의 실제 지분 이전 로그 → 거래 상세 |
| `/activity/[hash]` | 성공 receipt의 해당 CORE 계약 Transfer만 표시. 미존재·실패·다른 계약은 완료 처리하지 않음 |
| `/methodology`, `/limitations` | 공통 메뉴·본문 계층·문서 간 이동, 데이터 정책 |
| `/lab`, `/lab/strategies/[slug]` | 기존 KRW 모의 배분·내역·전략. USTX 및 테스트넷 장부와 명시적으로 구분 |
| `/lab/verification` | 기존 가격 변경 실험 |
| 이전 `/proof`, `/?app=select`, `/?app=portfolio`, `/etfs/[slug]` | 각각 대응 화면으로 이동 |
| `/design-preview` | 개발 환경에서만 예시 주문·보유·진행 상태. 운영에서는 404 |

공통 메뉴는 Markets / Portfolio / Activity다. 모바일 하단 메뉴, 키보드 포커스, 메뉴 바깥 클릭·Escape 닫기, 짧은 선택/상태 모션과 움직임 줄이기 CSS를 유지했다. 조회 오류는 0 또는 성공으로 바꾸지 않는다. 계정이 바뀌면 이전 계정 잔액을 보여주지 않는다.

장부 조회는 체인 ID, 배포 주소의 코드, decimals를 확인하고 같은 블록으로 잔액을 읽는다. 최근 2,000블록의 제한된 이력임을 화면에 표시하며 오래된 기록은 탐색기로 연결한다. 공개 RPC의 100블록 제한에 맞춰 최대 3개 동시 요청으로 나누어 읽는다. 계정 연결은 공개 주소 조회 권한 요청뿐이며 인증·서명·송금으로 사용하지 않는다. 공개 주소 편의 저장은 해당 탭의 sessionStorage만 쓴다.

## 배포

대상은 기존 `ganymede-xlayer` Worker와 기존 D1이다. 새 DB·계약·토큰·운영 자동화를 만들지 않는다. 환경 변수·비밀 값과 5분 일정은 유지한다. 배포 소스·Worker 버전 및 운영 확인 결과는 배포 후 이 절에 기록한다.

실자금 제품으로 확장하려면 결제·보관·취득·지급 구조와 계정 인증·견적·거래 상태 계약이 별도 구현되어야 한다. 현재 화면이 그 경로의 존재를 암시하지 않게 유지한다.
